# UFAZ GPA Calculator

## Overview

UFAZ GPA Calculator is a web-based calculator created for UFAZ L1-S2 students.  
It allows students to select their major and calculate their semester GPA based on course grades.

## Features

- Major selection page
- Separate GPA pages for:
  - Computer Science
  - Chemical Engineering
  - Chemistry
  - Petroleum Engineering
  - Geophysical Engineering
- Grade input fields for different subjects
- GPA calculation using JavaScript
- Responsive design
- Modern dark red/black interface

## Technologies Used

- HTML
- CSS
- JavaScript
